# vpn-dashboard

Дашборд для VPN-сервера на Amnezia (в духе 3x-ui) + защита от сканеров РКН. Одна установка — всё сразу.
Ставится рядом с тем, что уже установлено через приложение AmneziaVPN, и ничего в нём не меняет.

## Установка

Подключись к серверу под `root` и выполни:

```bash
curl -fsSL https://github.com/wellbob/vpn-dashboard/archive/refs/heads/main.tar.gz | tar xz && cd vpn-dashboard-main && bash install.sh
```

Установщик поставит дашборд и защиту от РКН, а в конце сам проверит, что всё работает, и покажет адрес.

1. Включи VPN и открой `http://172.29.172.1:8080`.
2. Войди: `admin` / `admin`, затем **смени пароль в «Настройках»**.
3. Адрес и логин всегда подскажет приветствие при входе на сервер по SSH.

Дашборд открывается **только из VPN**, из интернета он недоступен. Если на сервере нет сети Amnezia,
открывай через SSH-туннель: `ssh -L 8080:127.0.0.1:8080 root@сервер` → `http://127.0.0.1:8080`.

Работает на Ubuntu 20.04+ / Debian 11+ (Python 3.8+, systemd). Повторный запуск `install.sh` обновляет всё,
история и настройки сохраняются.

## Дашборд

- **Обзор** — процессор, память, swap, диск, скорость канала, пинг; график трафика клиентов со шкалой:
  за сутки (скорость) и за 30 дней (объём по дням).
- **Клиенты** — кто онлайн и с какого времени, скорость сейчас, трафик за сегодня / неделю / 30 дней / всё время.
  AmneziaWG 1.0 / 2.0 / 3.x и WireGuard, несколько протоколов сразу. Версия определяется по настройкам протокола,
  а не по имени контейнера.
- **История** — когда клиент подключался и отключался, сколько длилась сессия, сколько скачал, с какого IP.
- **Защита** — статус защиты от РКН, включение/выключение одной кнопкой, обновление списков, сколько попыток отбито.
- **Модули** — какие протоколы и сервисы Amnezia стоят (AmneziaWG, WireGuard, Xray/VLESS, OpenVPN, AmneziaDNS,
  AdGuard, SOCKS5 и др.), их порты и состояние; службы сервера (sing-box, 3x-ui, fail2ban, Docker…), если они есть.
- **Telegram-бот** — отвечает только на запросы и только тем, чей ID указан в настройках:
  📊 Сводка · 👥 Клиенты · 📜 История · 🛡 Защита · 🖥 Сервер.

### Подключить Telegram-бота

1. Создай бота у [@BotFather](https://t.me/BotFather) и скопируй токен.
2. «Настройки» → «Telegram-бот»: вставь токен, нажми «Сохранить».
3. Напиши своему боту что угодно — он ответит «Нет доступа» и покажет твой ID.
4. Вставь ID, нажми «Сохранить», затем «Проверить» — бот пришлёт тестовое сообщение.

## Защита от РКН (rkn-shield)

| | Что происходит | Зачем |
|---|---|---|
| **Входящие** | Подключения из ~1150 сетей РКН и госструктур отбрасываются на **всех портах сразу** — SSH, VPN, Docker и даже порты, которые откроются потом | Сканеры, которые ищут VPN-серверы, не получают ответа — сервер для них «не существует» |
| **Исходящие** | Сервер и клиенты VPN не ходят в сети VK / OK / Max | Эти сервисы не видят, что к ним ходят через твой сервер |

- Списки сетей обновляются автоматически раз в сутки, после перезагрузки защита включается сама.
- Обычные пользователи (МТС, Билайн, МегаФон, Ростелеком, домашний интернет) **не блокируются** — только сети ведомств.
- Это не бан: ничего не запоминается. Зашёл из сети ведомства — достаточно переключиться на мобильный интернет.

Команды на сервере:

| Команда | Что делает |
|---|---|
| `rkn-shield status` | Включена ли защита, сколько сетей в списках, сколько попыток отбито |
| `rkn-shield check 1.2.3.4` | Блокируется ли адрес |
| `rkn-shield allow 1.2.3.4` / `unallow` | Никогда не блокировать адрес / убрать из исключений |
| `rkn-shield off` / `on` | Выключить / включить |
| `rkn-shield update` | Обновить списки прямо сейчас |

Настройки — в `/etc/rkn-shield/config` (`BLOCK_IN`, `BLOCK_OUT`), после изменения `rkn-shield on`.
Если на сервере уже стоит плагин РКН из панели PRVTPRO, rkn-shield не ставится, чтобы защита не дублировалась.
Без защиты: `bash install.sh --no-rkn`.

## Команды установщика

```bash
bash /opt/vpn-dashboard/install.sh check            # проверить, что всё работает
bash /opt/vpn-dashboard/install.sh reset-password   # сбросить вход в дашборд на admin / admin
bash /opt/vpn-dashboard/install.sh uninstall        # удалить дашборд (защита остаётся)
bash /opt/vpn-dashboard/install.sh uninstall --all  # удалить всё
```

## Как устроено и почему безопасно

| Часть | Работает от | Что делает |
|---|---|---|
| `collector.py` | root | Раз в 15 с читает `awg/wg show` во всех контейнерах Amnezia, состояние модулей, служб и защиты, пишет `stats.json` |
| `dashboard.py` | пользователь `vpndash` без прав | Показывает `stats.json` на сайте и в боте. Нет доступа ни к Docker, ни к системе |
| `rkn-shield.sh` | root | Защита: списки сетей в `ipset`, фильтр на самом входе сервера (`mangle PREROUTING`) |

- Единственное, что дашборд может попросить у сборщика, — включить / выключить / обновить защиту от РКН.
  Сборщик выполняет только эти три команды, всё остальное отбрасывает.
- Пароль хранится как хэш (PBKDF2), после 10 неверных попыток вход блокируется на 5 минут.
- Счётчики трафика переживают перезапуск контейнеров и сервера.
- Только стандартная библиотека Python и bash, никаких внешних пакетов и CDN.

Тесты (без настоящего сервера): `python3 tests/test_all.py`
